# Infinite Scroll Gallery

## Mô tả

Gallery ảnh sử dụng API Lorem Picsum.

Cho phép:

* Load ảnh theo từng trang
* Infinite Scroll
* Lazy Loading
* Lightbox xem ảnh lớn
* Responsive Grid

## API sử dụng

### Lorem Picsum

Endpoint:

```text id="55udrt"
https://picsum.photos/v2/list?page=1&limit=20
```

## Tính năng

* Load 20 ảnh đầu tiên
* Tự động load thêm khi cuộn
* Hiển thị trạng thái loading
* Lazy loading ảnh
* Modal xem ảnh lớn
* Responsive 4/2/1 cột
