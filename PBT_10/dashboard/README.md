# Multi API Dashboard

## Mô tả

Dashboard tổng hợp dữ liệu từ nhiều API khác nhau.

Mỗi API hiển thị trong một widget riêng biệt.

## APIs sử dụng

### JSONPlaceholder Users

```text id="hqvtwv"
https://jsonplaceholder.typicode.com/users
```

### Random User

```text id="n6i7mf"
https://randomuser.me/api/?results=5
```

### Dog API

```text id="o3u4wo"
https://dog.ceo/api/breeds/image/random/5
```
